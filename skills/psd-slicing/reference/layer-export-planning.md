# 导出范围与方式判定

本文件只描述「决定哪些图层要导出、怎么合并/隐藏/命名」的规则。`list_layers`、`get_layer_info` 等命令写法见 [tool-usage.md](./tool-usage.md)。

## 原则与目标

- 从 PSD 导出**可复用 UI 素材**，不是机械复刻整屏。
- **只分析可见图层**，隐藏层跳过，不做状态推断。
- 图层范围**重合且语义相关**的可考虑合并导出；不要看到父组就直接整组导出。
- 导出位图时要**隐藏文字**；导出大背景时要**去掉其上的业务内容**。
- 严格按照以下步骤来决定图层导出方案，跑完全流程前不允许开始导出。

## 生成图层导出方案流程

### 1. 先看整体结构

1. 先导出一张**全屏图**（不改变当前显隐），用于识别重点控件与裁切优先级；该图仅作分析，不作为最终资源交付，分析后可删除。
2. 用 `list_layers` 查看全量图层树
3. 从目标区块**向下递归**扫描子节点。

### 2. 收集候选图层

1. 根据图层名、层级先做一个初筛，排除一些文字、全屏背景的图层。
2. 结构明显和其他图层重复的可以只选一个导出，同时把差异项也纳入候选图层
3. 其他图层都要纳入候选图层
4. 搜集候选图层所在的位置和尺寸信息，对比整体结构中的布局，检查是否有遗漏区域、遗漏的细节
    * 对候选图层用 `get_layer_info`，重点看：`kind`、`bbox`、`size`、是否文字层、是否组。
5. 再次抽查放弃的图层

### 3. 判断并规划导出项

1. 根据**2**获取到的尺寸位置信息，结合全屏图的分析，对候选图层做一个初步判断
2. 对于无法判断的候选图层，要获取更多子节点、父节点的信息来做一个判断，最终决定是否放弃
3. 结合图层的归类判断，规划导出方案
    * 文本图层需要隐藏
    * 花纹、装饰要合并导出
    * 选中状态要单独导出
    * 图标需要单独导出
    * 环绕文字的装饰、对称的需要合并导出
    * 背景通常需要隐藏其上所有内容，除了半透明的装饰、发光、投影、描边

### 4. 确认TODO项

根据前面搜集的信息，输出接下来要导出的图层和导出方案，方案要**展示给用户**
* 要合并导出的图层
* 导出时要隐藏的图层
* 导出后的文件名
* 是否是列表项


**命名前缀**

- 小型纯图形可独立复用：`icon_`
- 明显底板或点击承载区：`btn_`
- 背景区块：`bg_`
- 装饰、弱复用：`deco_` 或 `frame_`
- 「圆底/方底/胶囊底 + 箭头」类返回按钮，不要整体命名成 `icon_back`

语义名用英文或简短拼音，避免 `组 1`、`副本` 等无意义名。
